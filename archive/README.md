# Archived project snapshots

`legacy-MyTvTheme/` is the preserved older/experimental application tree from before the canonical Tizen app was consolidated under `app/`.

Do not import or build this archive as the TV application. The supported entry point is `../app/index.html`, with its Tizen manifest at `../app/tizen_web_project.yaml`.

`legacy-app-main.js.bak` is the backup file formerly stored beside the active `app/main.js`. It is retained for reference only.
